# Ship30 Style Guide

- Target a specific reader (e.g. first-time founders).
- Hook in the first 2–3 sentences.
- Short paragraphs (1–3 sentences).
- Clear H2/H3 headings.
- Bold key phrases sparingly.
- Bullets for frameworks and checklists.
- End with one clear takeaway and a Sources section.
- Approximate length: 1100–1400 words (warn if outside; do not fail).
