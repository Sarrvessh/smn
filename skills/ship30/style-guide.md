# Ship30 Style Guide (Signal)

Use this as the craft bar for every Ship30 essay. The system prompt owns structure and evidence rules; this guide owns **how it should feel**.

## Reader first

- Write to one specific reader, not “builders” or “everyone”.
- Make the cost of the problem visceral in the first screenful.

## Hook

- First 2–3 sentences must earn the next scroll.
- Prefer a tension, a failed playbook, or a precise observation over a definition.
- Never open with “In this essay…” or “Lenny’s guests often say…”.

## Rhythm

- Short paragraphs (1–3 sentences).
- Alternate denser explanation with a crisp bullet block.
- One idea per paragraph.

## Emphasis

- Bold sparingly: framework name, the atomic idea, one warning.
- Headings should be parallel and skimmable.
- Bullets for steps/checklists only.

## Evidence voice

- Paraphrase guests; don’t dump transcript sludge.
- Attribute: “As [Guest] notes…” only when Evidence supports it, then cite `[S#]`.
- When guests disagree, surface the disagreement—don’t average them into mush.

## Ending

- Close on one takeaway sentence a reader could screenshot.
- Sources section is mandatory when Evidence was used.

## Length

- Target 1100–1400 words.
- Soft band 900–1600. Prefer depth from Evidence over filler.
